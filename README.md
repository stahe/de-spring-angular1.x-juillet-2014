# Ein Client/Server-Beispiel – AngularJS 1.x / Spring 4

👉 Verwandter Kurs:
[Ein Client/Server-Beispiel – AngularJS 1.x / Spring 4](https://stahe.github.io/de-spring-angular1.x-juillet-2014/)

---

## 📌 Überblick

Dieses Dokument bietet eine gemeinsame Einführung in zwei wichtige Frameworks anhand der Implementierung einer **Client/Server**-Anwendung:

* **AngularJS 1.x** für die Client-Seite (Frontend)
* **Spring 4** für die Server-Seite (Backend)

Der Einfachheit halber werden im weiteren Verlauf dieses Dokuments die Begriffe **Angular** und **Spring** verwendet.

Ziel ist es, anhand von Technologien, die in der modernen Webanwendungsentwicklung weit verbreitet sind, ein konkretes Beispiel für die Interaktion zwischen einem Web-Client und einem Java-Server zu veranschaulichen.

---

## 🎯 Ziele

* Die Client/Server-Architektur verstehen
* AngularJS 1.x für die Frontend-Entwicklung implementieren
* Spring 4 zur Bereitstellung von Backend-Diensten nutzen
* Den HTTP-Austausch zwischen Client und Server veranschaulichen
* Eine Datenbank über JPA verwalten
